## Ramp up with Warp's Resource Center

Open the resource center by clicking the Warp icon in the top right corner of the window. Click tke keyboard icon (`CMD-/`) to view the keyboard shortcuts panel.

There are multiple sections that outline how to:

1. get started
1. make the most of Warp
1. set up advance features (like Custom Prompt and opening files in VS Code)
