# Command Inspector

Command Inspector surfaces documentation for sub-parts of your command, directly in Warp's Input Editor. Hover over which part of the command you want to inspect or press `CMD+I` to inspect at the cursor's current location.

Command Inspector Demo

Disable Command Inspector’s on hover trigger by navigating to our settings dialog (`Settings > Features`) which can also be accessed through the `Command Palette > Open Settings: Features`.
