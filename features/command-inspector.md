# Command Inspector

Command inspector allows you to surface documentation for subparts of your command directly in the input box. To trigger Command Inspector, simply hover over the part of the command you want to inspect or press `CMD+I` to inspect at the current cursor location.

If you wish to disable Command Inspector’s hover trigger, you can do so in `Settings > Features`.
