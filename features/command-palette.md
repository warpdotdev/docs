# Command Palette

## How to access it

{% tabs %}
{% tab title="macOS" %}
You can access the Command Palette with the keyboard shortcut `CMD-P`.
{% endtab %}

{% tab title="Linux" %}
You can access the Command Palette with the keyboard shortcut `SHIFT-CTRL-P`.
{% endtab %}
{% endtabs %}

## How it works

_Just start typing_ to quickly search for commands, keyboard shortcuts, or actions.&#x20;
