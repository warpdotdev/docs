# Command History

Hitting `↑` (UP) in the editor brings up your history.
While running, Warp isolates the history of each shell session e.g. if you have two Split Panes open, commands created in one pane do not populate the other pane's history.
Warp combines the history upon closing, however.

Pressing `CTRL-R` opens the history menu and initiates a search of your command history.
Use your `UP` `↑` and `DOWN` `↓` arrow keys, or mouse scroll, to navigate through them or filter using fuzzy search.

Warp bolds matching text when filtering with fuzzy search.
