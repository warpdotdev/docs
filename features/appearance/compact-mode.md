# Compact Mode

## What is it

Warp offers the option to enable Compact mode, which condenses the spacing between Blocks, enabling more content to be in view.

## How to access it

1. Compact Mode can be toggled through `Settings > Appearance > Compact Mode` or through the `Command Palette > Enable / Disable Compact Mode`.

_Note:_ Warp will (persist) open with the same settings in future sessions.
