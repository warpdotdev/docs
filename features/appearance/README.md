# Appearance Customization

Personalize Warp's appearance to your liking using custom themes.

Note: Warp does not yet support changing the transparency (modifying the opacity), subscribe to [this GitHub issue if you're interested.](https://github.com/warpdotdev/Warp/issues/17)

1. [Themes](themes.md) Warp includes a number of Default Themes and also supports setting custom themes.
2. [Custom Themes](custom-themes.md) can be created manually or via the [warp-themes.com](https://warp-themes.com/) tool.
3. [Prompt](prompt.md) shows your current working directory (cwd) and git branch information but can be replaced with a custom prompt.
4. [Compace Mode](compact-mode.md) condenses the spacing between Blocks, enabling more content to be in view.
