# Split Panes

## What is it

The Split Panes feature allows you to divide a tab into multiple rectangular _panes_, each of which is a unique terminal session. 

## How to access it

1. Split panes to the right with `CMD-D` and down with `SHIFT-CMD-D` or in any direction by right-clicking on any pane.
3. Navigate among split panes with `OPT-CMD-ARROW`, the active pane will be marked with a triangle in the top corner.
4. Toggle Maximize pane with `CMD-SHIFT-ENTER`.
5. Close the active pane with `CMD-W`.

_Note:_ You can find all the pane shortcuts by using the Command Palette `CMD-P` and remap them to your liking. See [Custom Keyboard Shortcuts](../features/keyboard-shortcuts.md#custom-keyboard-shortcuts) for more details.
