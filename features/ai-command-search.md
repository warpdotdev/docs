# A.I. Command Search

AI Command Search converts natural language descriptions into shell commands that can be executed. Currently, you need to be online to use this feature. The feature is backed by OpenAI’s codex engine (See how it works [here](https://openai.com/blog/openai-codex/)).

Press `` CTRL-` `` to open the AI Command Search panel. Type in the input box what you'd like to do and press `ENTER` to generate the command. Once the result shows up, press `CMD-ENTER` to input the generated command directly into Warp's Input Editor or modify the command description and `ENTER` to re-generate (make another query).

![AI Command Search Demo](https://user-images.githubusercontent.com/30107576/161656518-cbed1bbf-8a46-4ec0-90f3-21952c8d2386.gif)

## Privacy

Warp does not store any commands or prompts that users send. All inputs are sent directly to the OpenAI server. We only keep track of telemetry around opening and closing the A.I. Command Search panel. See OpenAI’s privacy policy [here](https://openai.com/api/policies/privacy/).
