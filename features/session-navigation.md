# Session Navigation

## What is it

The Session Navigation Palette helps you speed up your workflow by allowing you to quickly navigate via the keyboard or mouse to the terminal sessions you are looking for across panes, tabs, and windows.

## How to Access It

1. Open the Navigation Palette with `CMD-SHIFT-P` or switch between the Command Palette `CMD-P` and the Navigation Palette using `@` prefix.
2. Jump to a session by using your mouse or the `UP ↑`/`DOWN ↓` arrow keys and `Enter`.
3. Refine the session results by searching for sessions by prompt, the currently running command, last run command, and command status (ex: “Running…”, “Completed 10 minutes ago”, “Empty Session”).

_Note:_ Sessions are ordered by recency i.e. the most recently focused sessions show up first. The Navigation Palette does not have **PS1** support and can only show Warp's native prompt.
