# Command Entry

Warp's main features for Command Entry and History:

1. [A.I. Command Search](/features/entry/ai-command-search.md) (`` CTRL-` ``) converts natural language descriptions into shell commands that can be executed.
1. [Workflows](/features/entry/workflows.md) (`CTRL-SHIFT-R`) are an easier way to execute and share parameterized and searchable commands within Warp.
1. [Command Search](/features/entry/command-search.md) (`CTRL-R`) is a 3-in-1 panel that allows you to search across Command History, Workflows, Notebooks, and A.I. Command Search all at once.
1. [Command History](/features/entry/command-history.md) (`UP`) allows Warp to isolate the history of each shell session to make previously run commands easily accessible.
