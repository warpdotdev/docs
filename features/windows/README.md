# Window Managment

Warp's features for Window Management:

1. [Global Hotkey Window](/features/windows/hotkey-window.md) (`CMD-SHIFT-T`) is a customizable shortcut can show and hide Warp on your focused desktop regardless of whether the app is focused.
1. [Tabs](/features/windows/tabs.md) (`CMD-T`) allows you to organize a window into multiple terminal sessions.
1. [Split Panes](/features/windows/split-panes.md) (`CMD-D` / `SHIFT-CMD-D`) allows you to divide a Tab into multiple rectangular _panes_, each of which is a unique terminal session.
