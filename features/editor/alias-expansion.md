# Alias Expansion

## What is it

Warp will automatically expand your aliases as you type in the input editor.

## How to access it

When Alias Expansion is enabled, typing an alias then hitting `SPACE` will expand the alias.

To insert a space without expanding an alias, the default keybinding is `OPT-SPACE`.

> Note: Aliases will not be expanded when the command in the expanded form is the same as the alias itself. e.g. if you have an alias \`ls=”ls -G”\` defined, \`ls\` will not be expanded in the input editor.&#x20;

## How to enable / disable it

Alias expansion is disabled by default. There are two ways to toggle this on and off:

1. From Settings: Navigate to Settings > Features > Editor and toggle “Expand aliases as you type”
2. From the Command Palette: Press `CMD-P` to open the Command Palette. Then, search for the option to “Enable/disable alias expansion” and hit `ENTER`.
