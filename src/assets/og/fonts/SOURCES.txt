These fonts are used only by the build-time PNG renderer. They are not
downloaded by docs readers. The bundled fallback fonts use the SIL Open
Font License; accompanying *-OFL.txt files contain the license notices.

Inter is the docs site's primary typeface. Noto provides fallback glyphs
for CJK, Arabic, and emoji without depending on Vercel's system fonts.

Azeret SemiMono Regular and Medium are licensed brand fonts. Their WOFF2
files are not redistributed here. The renderer downloads the existing
public Warp marketing assets below, verifies pinned SHA-256 digests, and
caches them in node_modules/.cache/warp-og-fonts. Decoded fonts live only
in an OS temporary directory, never in git or the public build output.
A cold build requires network access; a warm cache works offline. A
download or checksum failure stops the build instead of replacing Azeret.
