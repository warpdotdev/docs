These fonts are used only by the build-time PNG renderer. They are not
downloaded by docs readers. All are distributed under the SIL Open Font
License; the accompanying *-OFL.txt files contain the license notices.

Inter is the docs site's primary typeface. Noto provides fallback glyphs
for CJK, Arabic, and emoji without depending on Vercel's system fonts.
