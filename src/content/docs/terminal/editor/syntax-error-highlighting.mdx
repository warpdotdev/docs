## What is Syntax Highlighting

Warp supports Syntax Highlighting in the [Input Editor.](/editor/) It colors each part of a command to help differentiate between sub-commands, options/flags, arguments, and variables.

:::caution
Newly installed apps or newly created aliases will not trigger syntax highlighting until you open a new Warp session (new window, tab, or pane), even if you `source` the RC files in the current session.
:::

### How to access Syntax Highlighting

When Syntax Highlighting is enabled, Warp's [Input Editor](/editor/) automatically recognizes each part of the command as you type it into the Input Editor, and syntactically highlight them.

### How to enable/disable Syntax Highlighting

Syntax highlighting is enabled by default, to toggle it:

* Through the [Command Palette](/command-palette/), search for the "Syntax Highlighting" option and click it (or press enter) to enable/disable.
* Through **Settings** > **Features** > **General** , toggle "Syntax highlighting for commands"

## What is Error Underlining

Warp highlights errors in commands that are typed within the [Input Editor](/editor/) e.g. if the binary for the command you've typed does not exist.

:::caution
Newly installed apps or newly created aliases will trigger error underlining until you open a new Warp session (new window, tab, or pane), even if you `source` the RC files in the current session.
:::

### How to access Error Underlining

When Error Underlining is enabled, Warp automatically underlines any invalid commands with a dashed red underline.

### How to enable/disable Error Underlining

Error underlining is enabled by default, to toggle it:

* Through the [Command Palette](/command-palette/), search for the "Syntax Highlighting" option and click it (or press enter) to enable/disable.
* Through **Settings** > **Features** > **General** , toggle "Error underlining for commands"
