Warp combines a terminal, editor, and agent workspace in one application. Run commands, work across tabs and panes, edit code, and start agent conversations without leaving your local development environment.

## Terminal work in Warp

* **Blocks** - Group each command and its output so you can search, copy, share, and revisit terminal work. See [Terminal Blocks](/terminal/blocks/).
* **Modern text editing** - Edit commands with multi-line input, cursor movement, selections, and familiar keyboard shortcuts. See [modern text editing](/terminal/editor/).
* **Command entry** - Search history, reuse commands, and save repeatable tasks as workflows. See [command entry](/terminal/entry/).
* **Windows and tabs** - Organize projects across tabs, panes, and sessions. See [Windows and tabs](/terminal/windows/).
* **Appearance and settings** - Configure themes, fonts, prompts, and terminal behavior. See [Terminal appearance](/terminal/appearance/).

Install Warp, run your first commands, and start an agent conversation with the [Warp quickstart](/quickstart/).
