Warp Enterprise gives organizations centralized administration, inference configuration, and contract-specific billing and support for development with agents.

Warp supports interactive development, cloud automation, and customer-defined software factories:

* **Warp Terminal** - Run commands, edit code, and work with agents interactively.
* **The {VARS.WARP_AUTOMATION_PLATFORM}** - Run and coordinate cloud agents from triggers, schedules, and APIs.
* **Warp Factories** - Build and operate your own software factories on Warp's infrastructure. Define workflows as code and use [evaluation and benchmarks](/factories/measure-and-improve/) to compare results.

Warp Terminal and agent plans are separate from Warp Factories plans. For plan guidance, see [plans, pricing, and refunds](/support-and-community/plans-and-billing/plans-pricing-refunds/); for current commercial details, see [Warp pricing](https://www.warp.dev/pricing). Enterprise usage pools, spending controls, and charges follow your [billing agreement](/enterprise/support-and-resources/billing/).

## Key capabilities

### Enterprise administration
* **Single Sign-On (SSO)** - Authenticate via your existing identity provider (Okta, Microsoft Entra ID, Google Workspace, and more)
* **Centralized Admin Panel** - Manage team settings, user permissions, and feature controls from one location
* **User roles and permissions** - Control access with Team Owner, Team Admin, and Member roles
* **Usage visibility** - Monitor team adoption and agent usage across your organization, and pull usage data programmatically with the [Analytics API](/enterprise/enterprise-features/analytics-api/)

### Security and compliance
* **Security reports** - Request reports through [Warp's Trust Center](/enterprise/security-and-compliance/trust-center/) to review their scope
* **Provider Zero Data Retention (ZDR)** - See the [provider policy and storage boundaries](/support-and-community/privacy-and-security/privacy/#zero-data-retention-zdr) and [model-specific exceptions](/agents/inference/model-choice/#models-requiring-provider-retention)
* **Open source client** - Warp's client code is published under [AGPL v3](https://github.com/warpdotdev/warp/blob/master/LICENSE-AGPL) at [`warpdotdev/warp`](https://github.com/warpdotdev/warp) for security review and audit
* **Bring Your Own LLM (BYOLLM)** - Route inference through your own cloud infrastructure (AWS Bedrock or Google Cloud via Gemini Enterprise)
* **Team-managed API keys and endpoints** - Share provider credentials for interactive sessions and cloud agents; see [eligibility by product](/enterprise/enterprise-features/team-managed-keys-and-endpoints/#plan-eligibility)
* **Flexible deployment** - Choose Warp-hosted or hybrid deployment models
* **Telemetry controls** - Configure what data is collected at the team level

### Team collaboration
* **Warp Drive team workspace** - Share Workflows, Notebooks, Prompts, Plans, Rules, and Environment Variables across your team
* **Codebase Context** - Team-level code indexing helps agents understand your repositories and generate accurate, context-aware responses
* **MCP integrations** - Connect to your team's tools (Linear, Sentry, Figma, GitHub, and more) for context-aware agent responses
* **Session sharing** - Collaborate on terminal sessions and conversations with shareable links

### Agent capabilities
* **Agent tools** - Run commands, edit code, and configure autonomy for agent tasks
* **Cloud agents** - Run background tasks in parallel, such as PR reviews across repositories. Warp-hosted runs have [concurrency limits and queuing](/factories/warp-hosting/#concurrency).
* **Run visibility** - Track cloud agent activity from the {VARS.DASHBOARD}
* **Agent Profiles** - Customize agent behavior, models, autonomy levels, and permissions
* **Rules and guardrails** - Guide agents with team-wide or project-specific instructions for coding standards, tech stack preferences, and security practices. Use repository checks, permissions, and approval policies to enforce specific requirements.
* **Harness choice** - Use the Warp Agent or supported third-party agents such as Claude Code and Codex. See [factory harness options](/factories/harnesses/).

## Getting started

:::note
Warp Enterprise is available through annual contracts. [Contact our sales team](https://www.warp.dev/contact-sales) to learn more or start a trial.
:::

**For IT admins**: Start with the [Admin Panel](/enterprise/team-management/admin-panel/) to manage team settings, configure agent policies, and enforce security controls. See [Roles and permissions](/enterprise/team-management/roles-and-permissions/) for user access details.

**For developers**: Jump to [Getting started for developers](/enterprise/getting-started/getting-started-developers/) to download Warp, log in, and start using key features like Codebase Context and Warp Drive. Or try the [Enterprise quickstart](/enterprise/getting-started/quickstart/) for a 10-minute walkthrough.

**For security teams**: Review our [Security page](https://www.warp.dev/legal/security) and [Privacy documentation](/support-and-community/privacy-and-security/privacy/) to understand how Warp handles data, encryption, and compliance.
