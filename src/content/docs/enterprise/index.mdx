Warp Enterprise is the plan for rolling Warp out across an engineering organization. It adds single sign-on, a central Admin Panel, usage reporting, and security and inference controls on top of Warp, the {VARS.WARP_AUTOMATION_PLATFORM}, and [Warp Factories](/factories/). Enterprise is sold on annual contracts; <a href={VARS.CONTACT_SALES_URL}>contact sales</a> to start a trial.

## What Enterprise adds

### Administration

* **Single Sign-On (SSO)** - Authenticate through Okta, Microsoft Entra ID, Google Workspace, OneLogin, or any SAML 2.0 or OIDC provider. See [Single Sign-On](/enterprise/security-and-compliance/sso/).
* **Admin Panel** - Manage team settings, permissions, and feature controls in one place. See the [Admin Panel](/enterprise/team-management/admin-panel/).
* **Roles** - Team Owner, Team Admin, and Member. See [roles and permissions](/enterprise/team-management/roles-and-permissions/).
* **Usage reporting** - Monitor adoption and agent usage across the organization, or pull the same data with the [Analytics API](/enterprise/enterprise-features/analytics-api/).

### Security and compliance

* **SOC 2 Type II** - Warp is certified; request the report through the [Trust Center](/enterprise/security-and-compliance/trust-center/).
* **Zero Data Retention (ZDR)** - Contracted LLM providers don't retain, store, or train on your data.
* **Bring Your Own LLM (BYOLLM)** - Route inference through your own AWS Bedrock or Gemini Enterprise account. See [Bring Your Own LLM](/enterprise/enterprise-features/bring-your-own-llm/).
* **Team-managed keys and endpoints** - Share provider API keys and custom endpoints across the team for interactive sessions and cloud agents. See [team-managed keys and endpoints](/enterprise/enterprise-features/team-managed-keys-and-endpoints/).
* **Deployment choice** - Warp-hosted, self-hosted execution, or hybrid. See [architecture and deployment](/enterprise/enterprise-features/architecture-and-deployment/).
* **Telemetry controls** - Set what Warp collects for the whole organization. See the [security overview](/enterprise/security-and-compliance/security-overview/).
* **Open source client** - Warp's client is published under [AGPL v3](https://github.com/warpdotdev/warp/blob/master/LICENSE-AGPL) at [`warpdotdev/warp`](https://github.com/warpdotdev/warp) for security review.

### Shared team configuration

* **Warp Drive** - Share Workflows, Notebooks, Prompts, Plans, Rules, and Environment Variables across the team. See [Warp Drive](/knowledge-and-collaboration/warp-drive/).
* **Codebase Context** - Index repositories at the team level so agents understand your code. See [Codebase Context](/agents/capabilities/codebase-context/).
* **Agent Profiles and Rules** - Set models, autonomy levels, permissions, and coding standards for everyone. See [Agent Profiles](/agents/capabilities/agent-profiles-permissions/) and [Rules](/agents/capabilities/rules/).
* **MCP servers** - Connect team tools such as Linear, Sentry, Figma, and GitHub. See [MCP](/agents/capabilities/mcp/).
* **Session sharing** - Share terminal sessions and agent conversations by link. See [session sharing](/agents/local-agents/session-sharing/).

## Where to start

* **IT and platform admins** - [Getting started for admins](/enterprise/getting-started/getting-started-enterprise/) covers SSO, creating the team, inviting users, and Admin Panel policies.
* **Developers** - The [Enterprise quickstart](/enterprise/getting-started/quickstart/) goes from SSO login to a first agent run in under 10 minutes. [Getting started for developers](/enterprise/getting-started/getting-started-developers/) covers the rest of setup.
* **Security reviewers** - Start with the [security overview](/enterprise/security-and-compliance/security-overview/) and [architecture and deployment](/enterprise/enterprise-features/architecture-and-deployment/), then the [Trust Center](/enterprise/security-and-compliance/trust-center/) and [privacy documentation](/support-and-community/privacy-and-security/privacy/).

Enterprise customers get priority support through a dedicated Slack or Microsoft Teams channel. See [feedback and feature requests](/enterprise/support-and-resources/feedback-and-feature-requests/).
