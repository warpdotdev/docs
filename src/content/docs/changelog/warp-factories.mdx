### 2026.10.05

**New features**

* Azure DevOps is now available. Use Azure DevOps repositories in cloud environments and factories, set up an Azure DevOps identity for a factory, run Azure DevOps automation triggers, and store a factory definition in Azure DevOps. ([#19064](https://github.com/warpdotdev/warp-server/pull/19064))
* Use the redesigned Secrets pages, import tasks from Linear or Jira on Runs, and start a new run from factory setup. ([#18925](https://github.com/warpdotdev/warp-server/pull/18925))

### 2026.10.01

**New features**

* Select third-party agent harnesses when launching factory benchmarks. ([#18515](https://github.com/warpdotdev/warp-server/pull/18515))

### 2026.09.28

**Improvements**

* Factory runs are now on the global Runs page instead of a per-factory Runs page. ([#18393](https://github.com/warpdotdev/warp-server/pull/18393))

### 2026.09.25

**Improvements**

* Factory runs show a live conversation with history, orchestration context, and follow-up messages. ([#18242](https://github.com/warpdotdev/warp-server/pull/18242))
* Declared Slack integrations for a factory now default to auto-respond and can be set to mention-only. ([#18215](https://github.com/warpdotdev/warp-server/pull/18215))

### 2026.09.24

**Improvements**

* Edit a managed MCP server's configuration from its Config tab. ([#18204](https://github.com/warpdotdev/warp-server/pull/18204))
