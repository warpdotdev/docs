Warp Runtime is an execution layer for Warp’s agentic development platform.\
\
It provides a secure, self-hosted environment where Warp's Agents can run commands, manage context, and interact with your codebase. You can use Warp Runtime inside of Warp, within any terminal, or in a remote server.
