Agent Session Sharing extends [Session Sharing](/knowledge-and-collaboration/session-sharing/) with agent activity and steering. Collaborators can inspect how an agent reached its result and, with edit access, send follow-up prompts or commands.

## What collaborators can see

An agent session can include:

* **Agent activity** - Prompts, responses, thinking states, tool use, plans, and follow-up messages.
* **Terminal context** - Commands and output from the session.
* **Live progress** - New agent and terminal activity as it happens.

People can open the shared session in the Warp app or a web browser, including on a mobile device.

## Sharing and steering an agent session

1. Open the agent session in the Warp app.
2. Follow the [steps for sharing a terminal session](/knowledge-and-collaboration/session-sharing/#sharing-a-terminal-session). When the session contains an agent conversation, Warp includes its history and uses **Share from start of session**.
3. Grant **View** access to reviewers who only need to watch. Grant **Edit** access to collaborators who need to send prompts, run commands, or steer the agent.

For third-party agent sessions that need persistent remote access, use [Remote Control](/agents/cli-agents/remote-control/).

## Access, retention, and sensitive data

### Who can access a shared session

Agent sessions use the same invited-user, team, and link permissions as terminal [Session Sharing](/knowledge-and-collaboration/session-sharing/#sharing-a-terminal-session).

### Data retention and access

The canonical Session Sharing page documents [plan limits](/knowledge-and-collaboration/session-sharing/#what-a-shared-session-contains), the [seven-day expiration, and how to stop sharing](/knowledge-and-collaboration/session-sharing/#stopping-sharing-and-expiration).

### Secrets in shared sessions

See the [Session Sharing warning](/knowledge-and-collaboration/session-sharing/#sharing-a-terminal-session) before sharing sensitive terminal or agent content. Secret Redaction does not apply.
