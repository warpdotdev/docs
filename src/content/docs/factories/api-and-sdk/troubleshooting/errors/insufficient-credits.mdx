The `insufficient_credits` error means the billed account does not have enough eligible usage to start a cloud run. The error code is the same for dollar-billed accounts and credit-based agreements.

Check the balance for the user or agent the run acts as. Agent API key runs use shared team usage, not the team owner's personal included allowance. See [cloud run billing](/platform/team-access-billing-and-identity/#billing-for-cloud-agent-runs) for schedule billing, dedicated allowances, and Enterprise terms.

---

## Details

* **HTTP Status:** `403 Forbidden`
* **Retryable:** No
* **Task State:** FAILED

---

## When does this occur?

This error is returned when:

* The billed user's or team's eligible balance is too low to start the run.
* Auto-reload is off or cannot replenish the balance, such as when a purchase is blocked by the team's limit.

See [purchasing additional usage](/support-and-community/plans-and-billing/add-on-credits/) for prices and purchase limits.

```json
{

  "title": "The principal billed for this run has no remaining credits. Purchase add-on credits or raise the team-wide spend cap to continue.",
  "status": 403,
  "instance": "/api/v1/agent/tasks",
  "retryable": false
}
```

---

## How to resolve

1. In the Warp app, open **Settings** > **Billing and usage** for the billed account or team.
2. On an eligible plan, [purchase usage](/support-and-community/plans-and-billing/add-on-credits/) or ask an admin to review auto-reload and the purchase limit. Alternatively, wait for the billed user's included allowance to reset.
3. Retry the failed operation after enough usage is available. The failed run is not retried automatically.
