A factory's model and runner choices control two usage charges: model inference and Warp-hosted runner time. Platform usage is separate; see [platform usage](/support-and-community/plans-and-billing/platform-credits/) for eligibility and rates.

Enterprise contracts can define different rates or credits. Follow your contract when its terms differ from the public rates.

## Model inference

Warp-provided inference is charged for input, cache-write, cache-read, and output tokens. Compare [models and token rates](/agents/inference/model-choice/#models-and-rates) when choosing a model for each factory agent.

Auto models and custom routers use the rate of the concrete model selected for each request. Reasoning can increase output-token usage, and provider tools such as web search can add charges beyond tokens.

Customer-supplied API keys, connected provider subscriptions, custom inference endpoints, and supported third-party harness credentials bill under the provider account's own terms. Claude Code and Codex use the provider credentials connected to the harness; moving harness aliases don't have a fixed token rate.

Check the [usage breakdown](/support-and-community/plans-and-billing/credits/#tracking-usage) for the categories consumed by a completed run. Provider-billed inference is not fully represented in Warp's totals.

## Warp-hosted runner time

Warp-hosted runs incur compute charges based on runner resources and time used. Choose an [operating system and runner shape](/factories/runners/#operating-systems) for your workload.
