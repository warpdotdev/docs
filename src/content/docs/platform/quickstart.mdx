Run one cloud-agent task from Warp in about 10 minutes. You'll set up an environment if needed, send a request, and inspect the result. For a standing workflow with factory agents and automations, use the [Warp Factories quickstart](/factories/quickstart/) instead.

## Prerequisites

* **Warp app** - Download from the [Warp download page](https://www.warp.dev/download).
* **Warp account** - Create an account from the <a href={VARS.WEB_APP_URL}>{VARS.WEB_APP}</a>

:::note
You need at least 20 credits available for this standalone workflow. See [cloud-agent access and billing](/platform/team-access-billing-and-identity/) for requirements.
:::

## Running your first cloud agent

_About 10 minutes_

### 1. Open Warp

Open the Warp app and sign in. This authenticates the cloud-agent setup flow with your Warp account.

### 2. Run the `/cloud-agent` command

In Warp's terminal input, type:

```bash
/cloud-agent
```

Warp checks for an environment and guides you through creating one if needed.

### 3. Create your environment

An environment defines the agent's workspace: a Docker image with your toolchain, repositories to check out, and commands to prepare them. It gives the agent the tools it needs even though it isn't running on your laptop.

If you already have an environment, use it. To create another for a different project, run `/create-environment` in Warp.

For a new environment, provide:

* **Name** - A label for this workspace.
* **Repositories** - Enter `owner/repo` or select a repository. Click **Auth with GitHub** if you need to authorize access.
* **Docker image** - Choose an image with your project's tools, such as `python:3.11` or `node:20`, or click **Suggest image**.
* **Setup commands** - Prepare dependencies with commands such as `pip install -r requirements.txt` or `npm ci`. Press `Enter` after each command.
* **Description** - Optional notes for teammates using the environment.

See [configuring environments](/platform/environments/configuring-environments/) for detailed setup.

### 4. Describe what you want the agent to do

Send a small, verifiable request, such as "Analyze test coverage and suggest one improvement. Do not change files."

The agent works in the cloud environment: it checks out the configured repositories and runs the setup commands before working on your prompt. Watch its progress in Warp and send follow-up instructions when needed. Agents can run commands and change files in that workspace; review their work before using it.

### 5. View run details

Inspect the commands, output, and any file changes to confirm the agent addressed your request:

* In the Warp app, open the [conversations panel](/agents/local-agents/interacting-with-agents/#conversation-panel) to see all your agent runs.
* Click the session link in your terminal output.
* Go to the <a href={VARS.WEB_APP_URL}>{VARS.WEB_APP}</a> and navigate to the **Runs** tab.

The run record remains available after execution finishes. See [viewing cloud agent runs](/platform/viewing-cloud-agent-runs/) for sharing, steering, and continuing sessions, including from a browser or mobile device.

**Prefer using the CLI?** See the [{VARS.WARP_AGENT_CLI} quickstart](/agents/cli/oz-cli/quickstart/) for CLI-based workflows.
