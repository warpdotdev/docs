## Evaluate a factory

A factory adds standing agent roles, connected work sources, work items, and automation stages around a shared set of repositories. See [how Warp Factories work](/factories/how-factories-work/) to decide whether that model fits your workflow, then use the [Warp Factories quickstart](/factories/quickstart/) to create one.
