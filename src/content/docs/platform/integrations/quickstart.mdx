Connect Slack to the {VARS.WARP_AUTOMATION_PLATFORM} to start cloud-agent tasks from a message or thread and receive updates in Slack.

For Linear setup, follow [Linear integration](/platform/integrations/linear/).

---

## Prerequisites

* **A Warp team** - Join an existing team or [create your first team](/platform/teams-and-admin-controls/#creating-your-first-team). The team must have a plan that supports [integrations](/platform/team-access-billing-and-identity/#requirements-for-integrations).
* **Usage balance** - Available usage for integration-triggered runs. Add usage if needed. See [cloud agent billing](/platform/team-access-billing-and-identity/#billing-for-cloud-agent-runs).
* **A cloud environment** - Agents run inside a configured environment that includes repos and other dependencies. If you don't have one yet, follow the [Cloud agents quickstart](/platform/quickstart/) or run `/create-environment` in Warp.
* **GitHub authorization** - Warp needs access to your repos to clone code and open PRs. You'll be prompted to authorize the Warp GitHub app when you first create the integration.

## 1. Connect the Slack integration

To connect Slack in the {VARS.WEB_APP}:

1. Navigate to the <a href={`${VARS.WEB_APP_URL}/integrations`}>Integrations page in the {VARS.WEB_APP}</a>.
2. Click **Slack**.
3. Follow the guided flow to select your environment and authorize the Warp app in your Slack workspace.

The integration is now available to your Warp team. Each teammate completes any account-linking or authorization prompts on first use.

**Using the {VARS.WARP_AGENT_CLI} instead:**

Run `oz integration create` to connect the Slack integration:

```bash
oz integration create slack --environment <ENV_ID>
```

Replace `<ENV_ID>` with your environment ID (see [Environments](/factories/environments/) if you need to create one). Find it with `oz environment list` on the {VARS.WARP_AGENT_CLI} or in the <a href={VARS.WEB_APP_URL}>{VARS.WEB_APP}</a>. The CLI opens a browser window to authorize the Warp app in your workspace.

:::tip
If the integration cannot be created or your first run cannot start, use the returned error code to narrow the fix. Common errors include:

* [`feature_not_available`](/factories/api-and-sdk/troubleshooting/errors/feature-not-available/) (plan does not support integrations)
* [`external_authentication_required`](/factories/api-and-sdk/troubleshooting/errors/external-authentication-required/) (missing GitHub or Slack authorization)
:::

To attach a default prompt that applies to every agent run triggered from this integration, add the `--prompt` flag:

```bash
oz integration create slack \
  --environment <ENV_ID> \
  --prompt "Always open a draft PR and request review from the team-leads group."
```

## 2. Tag the agent in Slack

In any channel or thread in your Slack workspace, tag @warp with a task:

> @warp scan the authentication module for security issues and summarize what you find

If Warp asks you to connect your Slack account, follow the link and sign in, then mention **@warp** again with your request. Complete any GitHub authorization requested for a run acting as you. Installation by another teammate does not connect your personal GitHub account. See [Slack identity and team access](/platform/integrations/slack/#identity-mapping-and-team-access).

After access is ready, confirm Warp acknowledges the request and posts run updates and a session link in the thread.

You can also tag @warp inside an existing thread. Warp picks up the full thread history as context automatically, so you can tag it mid-discussion without repeating background.

## 3. Watch the run

While the agent works, progress updates appear directly in the Slack thread. To inspect the run in more detail:

* **Click the session link** - Warp posts a link in the thread to open a live terminal view of the agent. Watch in real time, add follow-up instructions, or let it run to completion.
* **Go to the <a href={`${VARS.WEB_APP_URL}/runs`}>Runs page in the {VARS.WEB_APP}</a>** - See the full run transcript: status, commands executed, files changed, and agent output. See [Viewing Cloud Agent Runs](/platform/viewing-cloud-agent-runs/) for a complete walkthrough.

When the task is complete, Warp posts a summary back to the original Slack thread.
