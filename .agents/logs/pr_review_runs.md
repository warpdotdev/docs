# PR review run log

New entries are prepended by each `review-docs-pr` agent run on an agent-authored PR. Most recent entry first.

This log tracks every review of an agent-authored PR so the `improve-drafting-skills` outer loop can identify recurring patterns in agent drafting errors over time.

**Format**:
```markdown
## YYYY-MM-DD — PR #NNN [Approve | Approve with nits | Request changes]
- **Branch**: docs/branch-name
- **Skill used**: draft_feature_doc
- **Critical**: 0 · **Important**: 2 · **Suggestions**: 4 · **Nits**: 1
- **Top issue categories**: header_case (2), list_format (1), missing_frontmatter_description (1)
- **Oz run**: [run URL]
```
