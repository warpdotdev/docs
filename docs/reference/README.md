# Technical Reference

This section contains technical reference documentation for programmatically interacting with Warp.

## CLI

The [Warp CLI](cli/README.md) is the command-line interface for running Warp agents in non-interactive mode. Use it in CI pipelines, scripts, and server environments.

## API & SDK

The [Agent API & SDK](api-and-sdk/README.md) provides programmatic access to create and manage Ambient Agent tasks. Official SDKs are available for Python and TypeScript.
