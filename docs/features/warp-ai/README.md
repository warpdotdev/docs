# Warp AI

## What is Warp AI?

Warp AI is an AI-powered assistant that’s fully integrated within the Warp terminal.

{% hint style="info" %}
This feature sends input data to OpenAI servers through their API and is explicitly opt-in. Read more about data privacy for Warp features [on our privacy page](https://www.warp.dev/privacy).
{% endhint %}

## Warp AI includes:

* [Agent Mode](agent-mode.md) — Write natural language on the command line and walk through any dev task &#x20;
* [AI Command Suggestions (#)](ai-command-suggestions.md) — Quickly look up commands using natural language
* [AI Autofill ](../warp-drive/workflows.md#ai-autofill)in Warp Drive — Let Warp AI name and describe the workflows you create.
