# Model Choice

Warp lets you choose from a curated list of LLMs for use in Agent Mode. By default, Warp uses `Claude 3.7 Sonnet` for Auto and `Claude 3.5 Sonnet` for Lite, but you can switch to other supported models, including:

* **OpenAI**: `GPT-4o`, `GPT-4.1` ,`o4-mini`, `o3`, `o3-mini`&#x20;
* **Anthropic**: `Claude Sonnet 4` ,`Claude Opus 4` ,`Claude Sonnet 3.7`, `Claude Sonnet 3.5`, `Claude Haiku 3.5`
* **Google**: `Gemini 2.0 Flash`, `Gemini 2.5 Pro`

You can also select "auto" to let Warp automatically choose the best model for your task based on factors like query type and context.

When you start an agent mode conversation, you will be able to see the model being used.

<figure><img src="../../.gitbook/assets/agent-mode-prompt-sonnet.png" alt=""><figcaption><p>Agent mode prompt using Sonnet</p></figcaption></figure>

To change the model being used, click the current model name, 'claude 3.5 sonnet' in the example image above, to open a dropdown menu with the supported models. Your model choice will persist in future prompts.
