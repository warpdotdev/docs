# Sessions

1. [Session Navigation](session-navigation.md) enables you to easily navigate to any session in Warp.
2. [Session Restoration](session-restoration.md) automatically restores the window and tabs from your previous session.

For tab layout configuration, see [Tab Configs](../windows/tab-configs.md) and [Launch Configurations (Legacy)](launch-configurations.md) under [Windows and Tabs](../windows/README.md).
