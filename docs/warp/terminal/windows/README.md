# Windows and Tabs

1. [Tabs](tabs.md) allow you to organize a window into multiple terminal sessions.
2. [Vertical Tabs](vertical-tabs.md) replace the horizontal tab bar with a sidebar that shows rich metadata and drag-and-drop management for every tab and pane.
3. [Split Panes](split-panes.md) allows you to divide a Tab into multiple rectangular _panes_, each of which is a unique terminal session.
4. [Tab Configs](tab-configs.md) let you define reusable tab setups in a simple TOML file
5. [Global Hotkey](global-hotkey.md) is a configurable shortcut that can show/hide a dedicated window or all windows on your chosen desktop regardless of whether the app is focused.
6. [Launch Configurations (Legacy)](../sessions/launch-configurations.md) support saving a configuration of windows, tabs, and panes to open later.
