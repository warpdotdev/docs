# Agent notifications

Warp pipes through notifications from any supported coding agent — both in-app and via system desktop notifications — so you know exactly when your attention is needed. Whether an agent is waiting for command approval, flagging a code review, or reporting an error, Warp makes sure you see it.

Agent notifications currently work with Warp's Oz agent, Claude Code, and OpenCode.
