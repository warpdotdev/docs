# Agents in Warp

Warp's intelligent agents help you build, test, deploy, and debug while keeping you in control, whether you're working interactively in the desktop app or running automation in the cloud.

## Key capabilities

* [**Agent Mode**](local-agents/agents-overview.md) - Interactive AI agents embedded in the desktop app. Use natural language to write code, debug issues, run commands, and automate development tasks with full terminal access.
* [**Cloud Agents**](cloud-agents/cloud-agents-overview.md) - Autonomous, background agents that run automatically in response to system events, schedules, or integrations.
* [**Integrations**](cloud-agents/integrations/README.md) - Connect external system events to cloud agent execution. Use [Slack](cloud-agents/integrations/slack.md), [Linear](cloud-agents/integrations/linear.md), [GitHub Actions](cloud-agents/integrations/github-actions.md), and other integrations to trigger agents in the cloud.
* [**Cloud Agents Platform**](cloud-agents/platform.md) - The underlying infrastructure including the orchestration layer, environments, secrets, and management/observability.
