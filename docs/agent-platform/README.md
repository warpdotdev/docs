# Agents in Warp

Warp's intelligent agents help you build, test, deploy, and debug while keeping you in control, whether you're working interactively in the desktop app or running automation in the cloud.

## Key capabilities

* [**Agent**](agent/agents-overview.md) - Interactive AI agents embedded in the desktop app. Use natural language to write code, debug issues, run commands, and automate development tasks with full terminal access.
* [**Ambient Agents**](ambient-agents/ambient-agents-overview.md) - autonomous, background agents that run automatically in response to system events, schedules, or integrations.
* [**Integrations**](integrations/integrations-overview.md) - Connect external system events to Ambient Agent execution. Use [Slack](integrations/slack.md), [Linear](integrations/linear.md), [GitHub Actions](integrations/github-actions/), and other integrations to trigger agents in the cloud.
* [**Platform**](platform/warp-platform.md) - The underlying infrastructure including the orchestration layer, environments, secrets, and management/observability.
