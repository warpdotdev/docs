# Transparency (Opacity) and Blurring

## Transparency

Change Warp's opacity (configure the window's transparency) through `Settings > Appearance > Themes section`. The slider supports setting the opacity value between `1` and `100` where `100` is completely opaque (solid).

## Blurring

After adding some transparency (moving the slider to a value less than `100`), you can blur the background as well, using the blur slider.

Increasing the slider increases the blur radius that's applied to the background image. Note that large blur radiuses may cause affect performance (especially on Retina displays).
